# Hello World (free demo module)

A minimal **open-source** Trongate v2 module used to test the module marketplace.

## Install

1. Copy the `hello_world` folder into your app's `modules/` folder.
2. Open `https://your-site/hello_world`.

## Features

- Says hello
- Shows the module version
- MIT licensed - do what you like

See [Trongate](https://trongate.io) for the framework.
